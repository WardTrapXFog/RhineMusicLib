# RHINE MUSIC LIB

莱茵实验室风格的本地音乐播放器和三维 CD 展厅。首次进入时选择音乐文件夹，或者跳过并浏览空展厅。歌曲标题、歌手和专辑封面从音频元数据读取，展厅以档案标签陈列歌曲，播放页展示圆形唱片封面。

## 项目来源

本项目改编自 [LBEILC/RhineLabUI](https://github.com/LBEILC/RhineLabUI)。原项目的开屏、三维场景、动效和模型查看器仍是界面的基础；此版本加入本地曲库扫描、播放控制和 CD 陈列。原项目的版权声明保留在 [LICENSE](LICENSE) 中。

## 快速开始

需要 Node.js 20.19+ 或 22.12+，以及 npm。克隆本仓库后，在项目目录执行：

```sh
npm ci
npm run dev
```

打开终端显示的 `http://127.0.0.1` 地址。首次进入可点击「浏览…」选择文件夹；Windows 会打开系统文件夹选择窗口，其他系统可直接输入文件夹路径。点击「跳过」会进入空展厅，之后可在展厅点击「选择音乐目录」，或在右上角「设置」中更换路径。

```sh
npm run build
npm run preview
```

`npm run preview` 也会在本机提供曲库读取服务。直接打开 `dist/index.html` 或把静态文件单独部署到网页服务器时，页面无法读取本机音乐；请使用上述本地服务运行播放器。

## 操作指南

展厅可用鼠标、触摸、方向键和滚轮浏览，点击 CD 盒或按 Enter 进入播放页。播放页可播放、暂停、切换上一首与下一首、快退或快进五秒、拖动进度条和调整音量。歌曲结束后自动播放下一首。返回展厅后，底部控制条保留当前播放状态；检索、收藏和「360° 查看 CD 盒」也可使用。

曲库递归读取 MP3、FLAC、M4A、AAC、OGG、WAV 和 OPUS。标题、歌手、专辑、时长与封面优先取自元数据；缺少封面的歌曲使用默认盘面。文件能否播放取决于浏览器支持的解码格式。

## 本地数据

音乐文件不会复制进项目或上传到远程服务。开发与预览服务只监听 `127.0.0.1`；页面通过同源本机接口读取音频和封面。所选路径记录在本机的 `.rhine-music-config.json` 中，该文件已被 Git 排除。仓库不包含个人曲库、专辑图片或用户路径。
