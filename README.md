# RHINE MUSIC LIB

莱茵实验室风格的本地音乐播放器和三维 CD 展厅。首次进入时选择音乐文件夹，或者跳过并浏览空展厅。歌曲标题、歌手和专辑封面从音频元数据读取，展厅以档案标签陈列歌曲，播放页展示圆形唱片封面。

## 项目来源

本项目改编自 [LBEILC/RhineLabUI](https://github.com/LBEILC/RhineLabUI)。原项目的开屏、三维场景、动效和模型查看器仍是界面的基础；此版本加入本地曲库扫描、播放控制和 CD 陈列。原项目的版权声明保留在 [LICENSE](LICENSE) 中。

## 快速开始

Windows 用户克隆仓库后可直接双击 `启动音乐播放器.bat`，浏览器会自动打开。若项目依赖尚未安装，脚本会先执行安装。

需要 Node.js 20.19+ 或 22.12+，以及 npm。克隆本仓库后，在项目目录执行：

```sh
npm ci
npm run dev
```

打开终端显示的 `http://127.0.0.1` 地址。首次进入可点击「浏览…」授权浏览器读取文件夹；也可在本机服务中直接输入文件夹路径。点击「跳过」会进入空展厅，之后可在展厅点击「选择音乐目录」，或在右上角「设置」中更换路径。

```sh
npm run build
npm run preview
```

`npm run preview` 也会在本机提供曲库读取服务。部署到 HTTPS 静态网站后，Chrome 和 Edge 可通过「浏览…」直接授权读取本机文件夹；其他浏览器可使用本机启动脚本。静态网站不能根据手动输入的磁盘路径读取文件，也不会接收音乐文件上传。

## 操作指南

开场结束后停在歌曲展厅。展厅可用鼠标、触摸、方向键和滚轮浏览，上方可切换「全部」「专辑」「歌手」陈列，或从下拉列表直接跳转分类。每列对应当前分类，专辑内按曲序排列；分类偏好自动保存在本机，切换分类会保留正在播放的歌曲。

点击 CD 盒或按 Enter 打开声音档案，右侧显示档案概览、专辑曲目与载体记录，紧凑播放器支持播放、暂停、上一首与下一首、快退或快进五秒、拖动进度条和调整音量。可在「专辑曲目」中直接切歌。播放时页面盘面和三维 CD 封面持续旋转，暂停后停止；减少动态效果时关闭旋转。歌曲结束后按当前陈列顺序继续播放。返回展厅后，底部控制条保留当前播放状态；检索、收藏和「360° 查看 CD 盒」也可使用。

右上角「夜间／日间」切换整个系统配色，包括三维盒体、展厅标签、档案页、初始化窗口与系统设置；该偏好自动保存在本机。音源封面保留原图颜色。

曲库只读取所选文件夹中的 MP3、FLAC、M4A、AAC、OGG、WAV 和 OPUS，不扫描子文件夹。标题、歌手、专辑、时长与封面优先取自元数据；缺少封面的歌曲使用默认盘面。文件能否播放取决于浏览器支持的解码格式。

## 本地数据

音乐文件不会复制进项目或上传到远程服务。本机服务只监听 `127.0.0.1`，所选路径记录在已被 Git 排除的 `.rhine-music-config.json` 中。浏览器授权模式只在浏览器内读取文件，并在本机浏览器存储目录权限；需要时可重新选择。仓库不包含个人曲库、专辑图片或用户路径。
